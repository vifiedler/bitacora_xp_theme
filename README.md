# Bitácora XP

Tema de WordPress para «Mi experiencia con AJAX», examen JavaScript Avanzado 2026.

**Estado actual:** base de Underscores reorganizada y capa de acceso REST
preparada. Aún no se ha integrado la interfaz del RPG ni Phaser/Tiled.

Consulta `docs/ARQUITECTURA.md` para la organización, contrato de campos SCF,
ejemplos de consultas y procedimiento de instalación.

No se incluyeron recursos ni CPT de Entre Versos, porque no pertenecen a esta
experiencia. Los textos, páginas, categorías y NPC siguen en WordPress.
